# Nokia N95 RM-159

## Role
Primary device target for the first OMAP2420 compatibility implementation.

## Initial goals
1. Install/load an RM-159 firmware using the existing EKA2L1 iOS workflow.
2. Capture deterministic boot/runtime traces.
3. Identify the first unsupported low-level accesses or assumptions.
4. Implement only the minimum behavior required to pass each verified blocker.
5. Keep device-specific behavior inside the N95 profile until commonality is proven.

## Existing EKA2L1 relevance
Upstream EKA2L1 already recognizes RM-159/N95-class devices and includes S60v3 FP1 compatibility work. This project does not replace those HLE paths; it supplements them where low-level behavior is missing.

## Current state
Bootstrap only. No device test log has been collected in this repository yet.
