# OMAP2420 Research Notes

## Purpose
Track only facts and implementation observations relevant to the shared OMAP2420 compatibility layer.

## Known donor implementation
The UTM QEMU history contains OMAP2 and Nokia N8x0 machine code in older branches, including:
- `hw/arm/omap2.c`
- `hw/arm/nseries.c`
- `include/hw/arm/omap.h`

These files provide reference implementations for OMAP2420-era interrupt, timer, DMA, GPIO, I2C/SPI, MMC, flash, and display-related blocks.

## Rule
Do not assume the Nokia N95 board is electrically or logically identical to N800/N810 merely because the SoC family overlaps. Use donor code to generate hypotheses, then validate with N95 firmware traces and documentation.

## Implementation status
No OMAP2420 hardware shim has been committed yet. Current work is project/bootstrap setup.
